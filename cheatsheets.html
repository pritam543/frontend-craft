🌐 HTML5 Standard Structure

Standard clean HTML template with external stylesheet linking.

<!-- 1. Informs browser this is an HTML5 document --> <!DOCTYPE html> <html lang="en"> <head> <!-- 2. Sets character encoding for international characters --> <meta charset="UTF-8"> <!-- 3. Makes website responsive on mobile phones --> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Project Title</title> <!-- 4. External CSS Linking (Recommended clean practice) --> <link rel="stylesheet" href="style.css"> </head> <body> <!-- 5. Page Header --> <header>Navbar and Logo</header> <!-- 6. Main Content Area --> <main>Page Content Here</main> <!-- 7. External JS Script (Loaded at end for performance) --> <script src="script.js"></script> </body> </html>

📝 HTML5 Form Essentials

Clean inputs, labels, placeholders, and submit buttons.

📦 CSS Flexbox Essentials

Quick container properties for flexible responsive layouts.

.container { /* 1. Turns parent element into flex container */ display: flex; /* 2. Horizontal alignment: center | space-between | space-around */ justify-content: center; /* 3. Vertical alignment: flex-start | flex-end | center */ align-items: center; /* 4. Direction of items: row (default) | column */ flex-direction: row; /* 5. Wraps items to next line on small screens */ flex-wrap: wrap; /* 6. Spacing gap between child elements */ gap: 20px; }

🎯 Center Any Element in CSS

Modern CSS Grid trick to center content horizontally & vertically.

/* Method 1: The Modern CSS Grid Trick */ .parent-element { display: grid; place-items: center; /* Centers both X and Y axis instantly */ min-height: 100vh; /* Full screen height */ } /* Method 2: Responsive Card Grid System */ .card-grid { display: grid; /* Auto-fits columns based on available screen width */ grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 24px; /* Gap between cards */ }

Selecting HTML elements and attaching click event listeners.

🔄 Essential JS Array Methods

Quick reference for map, filter, find, and forEach methods.

const numbers = [10, 20, 30, 40, 50]; // 1. .map() - Transforms every item and returns new array const doubled = numbers.map(num => num * 2); // Result: [20, 40, 60, 80, 100] // 2. .filter() - Filters items based on condition const greaterThan25 = numbers.filter(num => num > 25); // Result: [30, 40, 50] // 3. .find() - Returns FIRST matching item const found = numbers.find(num => num === 30); // Result: 30 // 4. .forEach() - Loops through array items numbers.forEach(num => console.log("Number:", num));
